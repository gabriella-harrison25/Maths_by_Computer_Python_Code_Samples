# Machine Learning Project Overview
## Goal:
Complete an in-depth coursework project exploring the mathematical foundations of machine learning models, implement key algorithms manually alongside scikit-learn examples to validate results and further theoretical understanding.

## Organization
### Section A1 - Automatic Linear Regression
*Goal*: Build a linear regression model using scikit-learn to replicate results from Sathishkumar et al. (2020, Computer Communications) on a bike rental demand prediction using the Seoul Bike Sharing dataset.

### Section A2 - Manual Linear Regression
*Goal*: Build a linear regression model manually and apply it to a small, synthetic dataset.

### Section A3 - Logistic Regression for Binary Classification
*Goal*: Construct a logistic regression model from scratch for binary classification on a synthetic flower dataset.

### Section A4 - Hidden Layer Neural Network
*Goal*: Build a feedforward neural network with a hidden layer from scratch on the same flower dataset to compare accuracy in A3.

### Section B - Exploring Further Machine Learning Models
*Goal*: Explore further machine learning concepts and create example algorithms. Topics covered include: 
- Overfitting and underfitting
- Regularization
- Decision Trees
- Random forests
- K-Nearest Neighbors Classification
- K-Means Clustering
